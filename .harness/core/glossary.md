# Glossário do Projeto

> Vocabulário específico deste projeto. Garante consistência de nomenclatura
> entre IAs, devs e documentação. Adicione termos via `/harness-update`.

## Como usar

Antes de nomear entidades, funções, variáveis ou conceitos de domínio,
verifique se o termo já existe aqui. Se existir, use exatamente como definido.

## Formato de entrada

```
### {Termo}
**Tipo**: entidade | conceito | padrão | comando | acrônimo
**Definição**: O que é em uma linha.
**Uso correto**: Como deve ser usado no código/docs.
**Não confundir com**: Termos similares mas diferentes (opcional).
```
