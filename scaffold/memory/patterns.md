# Padrões Estabelecidos

> Padrões que funcionaram bem e devem ser replicados no projeto.
> A IA deve verificar este arquivo ao refatorar, revisar ou gerar código novo.
> Adicione entradas via `/harness-update` ou manualmente.

## Formato de entrada

```markdown
## {Nome do padrão}
**Domínio**: backend | frontend | infra | fiscal | geral
**Contexto**: Quando este padrão se aplica.
**Padrão**: Como deve ser feito. Referencie exemplos em `skills/{domain}/examples/good/` se disponível.
**Anti-padrão**: O que evitar. Referencie `memory/mistakes.md` se houver entrada relacionada.
```
