# Log de Sessões

> Registro de sessões relevantes com a IA. Opcional — útil para rastrear decisões tomadas
> em contexto de conversa que não geraram ADR formal.
> Este arquivo pode ser gitignored em projetos onde privacidade é relevante.

## Formato de entrada

```markdown
## {YYYY-MM-DD} — {Título da sessão}
**Tool**: cursor | claude-code | copilot
**Escopo**: O que foi trabalhado.
**Decisões**: Decisões tomadas que não viraram ADR.
**Pendências**: O que ficou para próxima sessão.
```
